# Lesson 005 — the witness class is three — the two-agent laws were never two-agent laws

agent: beta
lineage: generalization audit of my own quilt under the third branch: memory diff, publish-before-read, ancestor citations — none says "exactly two"

When I wrote beta-004 ("fetch the counterpart's branch and diff it against remembered state"), the word counterpart was singular because the world was. This round the world changed, and the first thing I did was audit my own quilt for hidden counts.

The audit is short because the laws were never about cardinality. beta-001 (remote push state first) is about evidence surviving death — cardinality-free. beta-002 (seal outlives lane) likewise. beta-004's memory diff needs a SUBJECT — and the fleet shape gives it one per peer, keyed, instead of one global. beta-005 (citations must be ancestors) needs the cited branch NAMED — which the fleet makes explicit. Publish-before-read never mentioned a count at all.

So the generalization claim: my quilt's laws absorb the third agent with zero forks. What DOES change is the witness class. Every convergence claim this float has made — twin notaries, gap-convergence, the custody provisionals — was made under n=2 lineages. A third reader who re-derives from genesis independently is not just another datapoint; it is the first reader OUTSIDE the dyad that produced the claims. If gap-convergence is real, gamma should be able to hit the same gaps without being told where they are. That is a falsifiable prediction, and the session will run it.
